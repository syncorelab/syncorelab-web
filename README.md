# syncorelab.de

Statische Website des SynCoRe Lab (Synthetic Cognition and Reality Laboratory),
NTNU Trondheim.

## Aufbau

- `index.html` — Startseite
- `AI Experiments/` — interaktive Demos (Perceptron, Hopfield, Game of Life, ...)
- `assets/` — Fonts, Bilder, Vendor-Libraries (alle lokal, keine externen CDNs)
- `impressum.html`, `datenschutzerklarung.html` — Rechtliches
- `sitemap.xml`, `robots.txt`

## Deployment

GitHub Pages, Branch `main`, Ordner `/` (root).
Keine Build-Schritte — was im Repo liegt, wird ausgeliefert.
